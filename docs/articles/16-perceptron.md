# 从零开始学机器学习 #16：感知机——神经网络的最小细胞

1958 年，一个叫感知机的模型问世时，媒体激动地预言：机器很快就能走路、说话、看见、写字、复制自己、意识到自己的存在。

结果呢？仅仅九年后，两位学者用一页纸的证明指出：单个感知机连"异或"这么简单的逻辑都学不会。这一击直接把神经网络研究打入了长达十几年的寒冬。

这个大起大落的小东西，就是这一篇的主角。它是神经网络最基本的单元——你可以把它理解成一个人工神经元。今天动辄千亿参数的大模型，最基础的building block，追根溯源就是它。前面十五篇讲的是经典机器学习，从这一篇开始，我们走上通往深度学习的桥，而感知机，就是桥的第一块砖。

## 一个模仿神经元的小东西

感知机的设计灵感，直接来自大脑里的神经元。

![感知机是对神经元的极简模仿](neuron_analogy.png)

生物神经元怎么工作？树突从四面八方收集电信号，细胞体把这些信号累加起来，一旦总和超过某个阈值，神经元就"放电"，把信号传给下一个。

感知机就是对这个过程的极简数学模仿：每个输入乘上一个权重（模仿不同信号的重要性不同），加权求和（模仿细胞体累加），如果总和超过阈值就输出 1、否则输出 0（模仿"放电还是不放电"）。

![感知机输入加权求和再过一道开关](perceptron_structure.png)

看这张结构图。左边是输入 x1、x2、x3，每个乘上自己的权重 w，汇聚到中间做加权求和，再过一个"激活开关"——超过阈值输出 1，不超过输出 0。就这么简单。

眼熟吗？第五篇的逻辑回归，结构几乎一模一样——都是"加权求和 + 一个激活函数"。区别只在激活函数：逻辑回归用平滑的 Sigmoid 输出概率，感知机用生硬的阶跃函数直接输出 0 或 1。所以我们当时说逻辑回归是"最小的神经网络"，现在可以说得更准确：**感知机和逻辑回归，都是单个神经元的不同变体。**

## 它怎么学：错了就改

感知机的学习规则，朴素得像小孩纠错。

一开始权重是随便设的，预测大概率是错的。感知机的办法是：**每处理一个样本，如果预测对了，什么都不做；如果预测错了，就朝着"下次能对"的方向微调权重。**

具体说，如果真实答案是 1、它却猜了 0（猜小了），就把权重往上调一点，让加权和变大、下次更容易过阈值；反过来猜大了就往下调。调整的幅度由学习率控制——又是第二篇那个老朋友。

```python
def fit(self, X, y):
    for _ in range(self.n_iters):
        for xi, target in zip(X, y):
            pred = self.predict(xi)            # 当前预测
            update = self.lr * (target - pred)  # 错了才非零
            self.w += update * xi               # 朝正确方向调权重
            self.b += update
```

注意那行 `target - pred`：预测对了它就是 0，权重不动；错了才产生调整。这个"错了才改、对了不动"的规则，简单却有效。数学上能证明：只要数据是线性可分的，感知机一定能在有限步内找到一条完美分开两类的直线——这条性质叫"感知机收敛定理"，是它最漂亮的理论保证。

## 异或问题：那个致命的死穴

但感知机有个致命弱点，就藏在上面那张图的右边。

![线性可分感知机搞定异或搞不定](e1_perceptron.png)

看这张真实跑出来的对比图。左边是线性可分的两类点，感知机干脆利落画出分界线，全分对——这是它风光的一面。右边的四个点，是"异或"（XOR）问题：两个输入相同（都是 0 或都是 1）时输出 0，不同时输出 1。你盯着这四个点看——对角线上的两个点是一类，另一条对角线上的两个是另一类。

试试用一条直线把它们分开。你会发现：不可能。无论直线怎么画，总有一个点会站错队。这就是感知机的死穴：**它只能画一条直线，而异或问题天生就不是一条直线能分开的。**

1969 年，Minsky 和 Papert 就是用这个简单的异或问题，证明了单个感知机的能力上限，直接引发了神经网络的第一次寒冬。研究经费撤了，学者转行了，这个方向沉寂了十几年。

可故事还有后半段。人们后来发现：单个感知机不行，**把多个感知机堆成多层，中间加上非线性，就能解决异或——也能解决几乎任何复杂问题。** 那条分不开的直线，用两层网络一掰，就变成了能绕开的曲线。这个"多层"的突破，正是下一篇反向传播要讲的，也是深度学习真正的起点。

说白了就是：**感知机的失败不是终点，而是把人们逼向了"多层"这条正确的路。** 有时候，一个模型的局限性，反而指明了下一个突破的方向。

## sklearn 一行，和它的历史地位

```python
model.predict(X_new)
```

![感知机的大起大落是神经网络命运曲线](history.png)

今天几乎没人单独用一个感知机做实际任务——它太弱了。它的价值全在教学和历史：理解了单个神经元怎么工作、为什么会失败，你才能真正理解为什么神经网络要"深"、要"多层"、要非线性激活。

感知机这段大起大落的历史，藏着一个深刻的教训：**别被一个模型的初期局限吓退。** 感知机的寒冬持续了十几年，可一旦"多层 + 反向传播"的钥匙被找到，同样的基本单元就爆发出了改变世界的力量。今天的 GPT、Sora，最底层的那个计算单元，依然是这个 1958 年的小东西的后代。

下一篇是整个系列最硬核、也最关键的一篇：反向传播。它是让多层神经网络能够训练起来的核心魔法，也是把感知机从寒冬里救活、最终点燃深度学习的那把火。别担心，我会用最直白的方式，让你看清这个"魔法"其实就是高中学过的链式求导。
