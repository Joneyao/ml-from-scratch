# 从零开始学机器学习 #05：逻辑回归——为什么"回归"能做分类

这个算法的名字，是机器学习里最坑新人的一个。

它叫逻辑回归，名字里带"回归"，干的却是分类的活——判断一封邮件是不是垃圾邮件、一个肿瘤是良性还是恶性、一个用户会不会流失。全是"是"或"否"的问题，跟预测房价那种"回归"八竿子打不着。

上一篇我们让直线学会了预测数值。这一篇，我们给它加一个小小的零件，就让它学会了回答"是"或"否"。这个零件叫 Sigmoid，是理解逻辑回归的钥匙，也是通往神经网络的第一块踏板。

![逻辑回归用一条直线分开两类](b2_logistic_boundary.png)

先看结果：逻辑回归在两类点之间画出了一条分界线。线一边判为红类，另一边判为蓝类。可它明明是个"回归"，怎么就画出分界线了？

## 直线预测数值，但分类要的是概率

先想清楚一个问题：分类和回归，到底差在哪。

回归的输出是一个连续数值——房价可以是 315 万、也可以是 316.5 万。而分类的输出只有几个离散选项——是垃圾邮件，或者不是，没有中间地带。

![回归输出连续值分类输出离散类别](reg_vs_cls.png)

线性回归的 `wx + b` 输出的是什么？是一个能取任意值的数——可能是 -20，可能是 0.5，可能是 1000。你没法直接拿这个数当类别。判断"是不是垃圾邮件"，你需要的是一个 0 到 1 之间的概率：0.9 表示"很可能是"，0.1 表示"很可能不是"。

问题来了——怎么把 `wx + b` 那个能取任意值的数，变成一个规矩的 0 到 1 的概率？

这就是 Sigmoid 登场的地方。

## Sigmoid：把直线掰成概率的魔法

Sigmoid 是一个函数，长得像拉长的 S。它的本事只有一个：不管你喂进去多大或多小的数，它都给你压到 0 和 1 之间。

![Sigmoid把直线输出掰成0到1的概率](sigmoid.png)

看这条 S 曲线。喂进去一个很大的正数，它输出接近 1；喂进去一个很大的负数，输出接近 0；喂进去 0，正好输出 0.5——也就是"拿不准，五五开"。

于是逻辑回归的完整流程就清楚了：先用线性部分 `wx + b` 算一个数，再用 Sigmoid 把这个数掰成 0 到 1 的概率，最后拿 0.5 当门槛——概率大于 0.5 判为正类，小于 0.5 判为负类。

![逻辑回归等于线性回归加一层Sigmoid](reg_to_cls.png)

看明白这张图，你就懂了逻辑回归的全部秘密：**它就是线性回归后面接了一层 Sigmoid。** 名字叫"回归"，是因为它骨子里那个 `wx + b` 确实是回归；但加了 Sigmoid 这层壳，它就干起了分类的活。

这个"线性部分 + 一层非线性函数"的结构，你一定要记牢。因为神经网络的一个神经元，长的就是这个样子——加权求和，再过一个激活函数。逻辑回归，可以说就是最小的神经网络，只有一个神经元。这条线我们会在这个系列的收尾篇里接上。

## 它怎么学：用交叉熵找最好的分界线

Sigmoid 解决了"怎么输出概率"，但还有个问题：`w` 和 `b` 怎么定？分界线画在哪才最好？

老套路——定一个损失函数，然后梯度下降。但逻辑回归的损失函数不用上一篇那个均方误差，它用的是交叉熵。

交叉熵的直觉很朴素：模型说"90% 是垃圾邮件"，结果真是垃圾邮件，那损失很小，奖励它；模型信誓旦旦说"99% 不是垃圾邮件"，结果偏偏是，那损失巨大，狠狠罚它。**说得越自信、错得越离谱，罚得越重。** 这种赏罚机制逼着模型输出诚实的概率。

![交叉熵损失越自信错得越离谱罚得越重](cross_entropy.png)

前面那张两类点被一条线分开的图，就是这套机制训练出来的结果——交叉熵驱动梯度下降，一点点把分界线挪到最能分开两类的位置。

有了交叉熵这个损失，剩下的就是老朋友梯度下降了：

```python
def fit(self, X, y, lr=0.1, n_iters=1000):
    self.w = np.zeros(X.shape[1])
    self.b = 0.0
    for _ in range(n_iters):
        p = self.sigmoid(X @ self.w + self.b)   # 预测概率
        error = p - y                            # 预测概率和真实标签的差
        self.w -= lr * (X.T @ error) / len(y)    # 梯度下降更新
        self.b -= lr * error.mean()
```

有意思的是，你把这段代码和上一篇线性回归的梯度下降放一起看，几乎一模一样——都是算误差、更新参数。唯一的区别就是预测那一步多套了个 Sigmoid。前几篇的地基，到这里全用上了：模型、损失、梯度下降，一个都没浪费。

## sklearn 一行，和它的真实战场

照例，工业界怎么用：

```python
from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
model.fit(X, y)
model.predict_proba(X_new)   # 输出概率
```

还是熟悉的三行。但这次你已经知道 `predict_proba` 那个概率是怎么来的了——线性算个数，Sigmoid 掰成概率。

别看逻辑回归简单，它是工业界用得最多的分类算法，没有之一。信贷风控判断你会不会违约、广告系统预测你会不会点击、医院辅助判断疾病风险——大量场景的第一版模型都是它。原因是它够快、够稳、还能输出概率（不只是给个类别，还告诉你有多确信），而且结果可解释——每个特征的权重 `w` 直接告诉你它对结果影响多大，是正是负。这在需要向监管或客户解释"为什么拒绝你贷款"的场景里，太重要了。

![逻辑回归在信贷广告医疗运营的应用](applications.png)

说白了就是：逻辑回归不是最强的分类器，但常常是最实用的那个。
