# 从零开始学机器学习 #09：SVM——找一条"最宽"的分界线

在深度学习火起来之前，有一个算法统治了机器学习整整十几年，是无数比赛和论文的默认首选。它就是 SVM，支持向量机。

前面我们学过好几个能"画分界线"的算法——逻辑回归画一条、决策树画阶梯。SVM 也画线，但它对"什么是好的分界线"有一套独到而漂亮的想法：不满足于随便一条能分开数据的线，而是要找那条**离两边都最远、留出最大余地**的线。

这个"最大余地"的思想，加上一个叫核技巧的绝招，让 SVM 既优雅又强大。这一篇讲清楚这两样东西。它们是这个系列里数学味最浓的一站，但我保证用最直白的话讲明白。

## 不只是分开，而是留最大的余地

先看一个问题：两类点摆在那儿，能把它们分开的直线有无数条。哪条最好？

![很多线都能分开SVM挑间隔最宽的](max_margin.png)

看左边，随便画几条线，都能把红蓝分开。逻辑回归可能挑其中任意一条，只要它分对了就行。但 SVM 不干——它觉得这些线都不够好，因为有的线贴红点太近，有的贴蓝点太近。万一来个新点稍微偏一点，就容易判错。

SVM 的选择是右边那条：它找的是**离两边最近的点都尽可能远**的那条线。你可以想象在两类之间修一条马路，SVM 要修的是能修的最宽的那条路，路的正中线就是分界线。这条"最宽的路"的宽度，叫间隔（margin），SVM 的全称"最大间隔分类器"就是这么来的。

为什么要留最大余地？因为余地就是容错空间。间隔越宽，新数据稍有偏差也不容易越界判错，模型的泛化能力就越强。**分对不难，难的是分得稳。** 这是 SVM 比"随便分开就行"高明的地方。

那些恰好压在马路边缘、决定了这条路能修多宽的点，就叫支持向量——SVM 这个名字的另一半来源。有意思的是，最后的分界线只由这几个支持向量决定，其他点离得远、根本不影响结果。这也是 SVM 的一个优点：抓关键点，不被无关数据干扰。

## 核技巧：把分不开的数据"掰弯"

最大间隔很美，但有个硬伤：现实中很多数据，你用任何直线都分不开。

最经典的例子：红点聚在中间，蓝点围成一圈把红点包起来。你拿直尺怎么划，都没法把里圈的红和外圈的蓝分开。SVM 的最大间隔到这儿好像就卡住了。

这时候，SVM 掏出了它最惊艳的绝招——核技巧。

![核技巧低维缠在一起高维一刀两断](kernel_trick.png)

看这张图。左边是平面上的困局：红点被蓝圈包着，一条直线束手无策。但如果我们给每个点加一个新维度——比如让它"离中心越远就抬得越高"——会发生什么？看右边：外圈的蓝点因为离中心远，被抬到了高处；中间的红点离中心近，留在低处。它们在三维空间里分层了！这时候拿一个水平的平面轻轻一切，红蓝就干净利落地分开了。

这就是核技巧的核心思想：**低维空间里分不开的数据，升到高维往往就分得开了。**

而"核技巧"里那个"技巧"更妙。你以为要真的把每个点都算到高维空间去？不用。核函数能直接算出两个点"在高维空间里的关系"，跳过了显式升维那一步——省了大量计算。最常用的 RBF 核（高斯核），效果就是能画出各种弯曲的分界线，去贴合那些线性分不开的数据。

我们用配套仓库里手写的 SVM，真跑一下线性和 RBF 两种情况：

![线性SVM与RBF核在月牙数据上的边界](b6_svm.png)

左边是线性 SVM 在能直线分开的数据上，画出笔直的最宽分隔带。右边是两个交缠的月牙形——直线绝对分不开，但 RBF 核画出了一条弯曲的边界，把它们顺顺当当分开了。同一个 SVM，换个核，就从"只会画直线"变成了"能画各种曲线"。

## sklearn 一行，和它的黄金时代

工业界用法：

```python
from sklearn.svm import SVC
model = SVC(kernel="rbf")   # 用 RBF 核，能处理非线性
model.fit(X, y)
model.predict(X_new)
```

那个 `kernel` 参数就是选核函数——`linear` 画直线，`rbf` 画曲线。你现在知道换这个参数意味着什么了：它决定 SVM 在多高的维度里去找那条最宽的分界线。

SVM 曾经是王者。2000 年代到 2010 年代初，中小规模数据上它几乎是最强分类器，手写数字识别、文本分类、生物信息，到处是它的身影。后来深度学习在大数据、图像语音上崛起，SVM 才退居二线。

![SVM从王者到专才的地位变迁](svm_timeline.png)

但它没有过时。数据量不大、特征维度高（比如文本）、又要求分类精准的场景，SVM 至今是很有竞争力的选择。而它那个"最大间隔"和"核技巧"的思想，更是影响深远——理解了它们，你对"什么是好的决策边界""怎么处理非线性"会有更深的直觉。

到这里，监督学习这条线我们走完了：从线性回归到 SVM，六个算法，六种不同的思路去回答同一个问题——给定输入，怎么预测输出。它们有的靠优化损失，有的靠数邻居，有的靠算概率，有的靠问问题，有的靠找最宽的间隔。没有哪个是万能的，各有各的地盘。
