# 从零开始学机器学习 #11：GBDT——每一棵树都在纠正前一棵的错

如果说随机森林是"一群专家同时投票"，那这一篇的 GBDT 就是"一群专家排队接力，每个人专门修正前一个人的错"。

它们都用决策树，都属于集成学习，但组合的哲学完全相反。上一篇的随机森林让树们并行、独立、求同；GBDT 让树们串行、依赖、补短。有意思的是，这个"补短"的思路，造出了表格数据上至今最能打的模型之一——XGBoost、LightGBM 这些竞赛常胜将军，骨子里都是 GBDT。

这一篇讲清楚 GBDT 的核心动作：什么叫"拟合残差"，以及为什么"一棵接一棵地纠错"能不断逼近正确答案。

## 两种组合树的思路，正好相反

先把 GBDT 和上一篇的随机森林摆一起看，区别一目了然。

![并行投票与串行纠错两种组合思路](bagging_vs_boosting.png)

左边是随机森林：每棵树独立训练，互不相干，最后一起投票。它靠的是"数量多、错得不一样，错误互相抵消"。

右边是 GBDT：树们排成一队，第一棵先学，学得不够好没关系；第二棵专门盯着第一棵没学好的地方去补；第三棵再补前两棵合起来还没学好的地方……一棵接一棵，像接力赛。它靠的是"步步纠错，逐渐逼近"。

一个求同，一个补短。随机森林的树可以同时训练（并行），GBDT 的树必须一个训练完才能训练下一个（串行）——因为后一棵要看前面的结果。这也是 GBDT 训练通常比随机森林慢的原因。

那"专门纠正前一棵的错"具体怎么做到？关键在一个词：残差。

## 残差：每棵树只管补前面没学会的

残差这个词，第三篇（讲线性回归时）见过——就是真实值和预测值之间的差距，也就是"还没学会的部分"。

GBDT 的核心动作，就是让每棵新树去拟合当前的残差。

![残差接力每棵树补前面没学会的部分](residual_relay.png)

看这个过程。第一棵树上场，对着真实目标学，学个大概，留下一堆残差（图里第一张的红线，就是它没搞定的部分）。第二棵树不去重新学目标，而是专门学第一棵留下的残差——把那部分误差补掉一些，残差就变小了（第二张）。第三棵树再学前两棵合起来剩下的残差……

每补一轮，残差就小一圈。所有树的预测加起来，就一步步逼近了真实目标。

用代码看，GBDT 的骨架惊人地简洁：

```python
def fit(self, X, y):
    self.init_ = y.mean()            # 初始预测：就用平均值
    pred = np.full(len(y), self.init_)
    for _ in range(self.n_estimators):
        residual = y - pred          # 当前还没学会的部分
        tree = RegressionTree(max_depth=self.max_depth)
        tree.fit(X, residual)        # 新树专门拟合残差
        pred += self.learning_rate * tree.predict(X)   # 把这棵树的修正加进来
        self.trees_.append(tree)
```

注意那个 `learning_rate`（学习率）——它控制每棵树的修正力度。设小一点，每棵树只补一点点，需要更多树，但不容易过头；设大了容易冲过头。这个权衡，和第二篇梯度下降里的学习率是同一个道理。前面的地基，又一次用上了。

说白了就是：**GBDT 不追求一棵树全对，而是让每棵树认领一点错误去改，改着改着就对了。**

## 看着残差一轮轮消下去

光说不够，用配套仓库手写的 GBDT，真跑一个拟合任务，让你看到残差是怎么消下去的。

![GBDT训练误差下降与拟合逐步贴合](c2_gbdt_residual.png)

我们让 GBDT 去拟合一条正弦曲线（带噪声）。左边这张图是训练误差随树的棵数的变化——每加一棵树，误差就降一截，头十几棵降得最猛，之后慢慢收敛。这就是残差被一轮轮补掉的直接体现。

右边更直观：只有 1 棵树时，拟合是一条粗糙的阶梯，离真实曲线差得远；5 棵树时开始有了形状；60 棵树时，预测已经紧紧贴住了真实的正弦曲线。**树越多，补得越细，拟合越准。**

这也暴露了 GBDT 的一个风险：树太多、学习率太大，它会连噪声都补进去——又是过拟合。所以 GBDT 特别依赖调参，树的棵数、学习率、树的深度都要仔细权衡。这是它比随机森林难伺候的地方，但调好了，威力也更大。

## sklearn 一行，和它的竞赛统治力

工业界用法：

```python
from sklearn.ensemble import GradientBoostingRegressor
model = GradientBoostingRegressor(n_estimators=100, learning_rate=0.1, max_depth=3)
model.fit(X, y)
model.predict(X_new)
```

那三个参数——树的棵数、学习率、树深——就是我们刚讲的三个关键旋钮。你现在知道调它们意味着什么了。

![GBDT的高效后代XGBoost等竞赛常客](gbdt_family.png)

GBDT 的地位有多高？在结构化表格数据的竞赛里，它几乎是默认答案。Kaggle 上无数获奖方案的核心都是 GBDT 的高效实现——XGBoost、LightGBM、CatBoost。这些名字你以后一定会反复听到，它们本质上都是"把 GBDT 做得更快、更强、更好调"的工程杰作。有个流传很广的说法：结构化数据上，先无脑试试 GBDT，很多时候它就是最优解。

到这里，集成学习的两种主力思路你都握住了：随机森林的并行求同，GBDT 的串行补短。它们代表了"组合弱模型"的两个方向，也是经典机器学习性能的天花板——在表格数据上，它们至今常常能打败复杂的神经网络。
