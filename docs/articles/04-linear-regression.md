# 从零开始学机器学习 #04：线性回归——从一条直线开始

前三篇我们把地基打好了：机器学习就是在损失这个碗里找最低点，梯度下降负责往下滑，过拟合是要提防的敌人。地基能不能撑住，得盖一栋真楼试试。

这一篇，我们盖第一栋——线性回归。它是机器学习里最老、最简单的算法，1805 年就有了，比计算机还早一百多年。但别小看它：今天的房价预测、销量预估、风险评分，底层跑的常常还是它。更重要的是，它把前三篇的抽象概念全落到了实处，是你真正上手的第一个模型。

我们要做的事很简单：给一堆点，找一条最贴合它们的直线。

![线性回归找一条最贴合数据的直线](b1_linear_fit.png)

这条红线就是线性回归的成果——它抓住了数据的整体趋势。可"最贴合"这三个字，机器是怎么理解的？这就是整篇的核心。

## 一条直线，怎么算"最贴合"

回到那个房价的例子。横轴是面积，纵轴是价格，每套房子是一个点。我们想找一条直线 `y = wx + b`，让它尽量贴近所有点。

问题是"贴近"没法用眼睛量。机器需要一个能算的标准。

标准是这样的：对每个点，量一下它到直线的**竖直距离**——真实价格和直线预测价格差多少。这个差叫残差。把所有残差平方后加起来，就是总误差。哪条直线的总误差最小，它就最贴合。

![最小二乘让残差平方和最小](residuals.png)

看这张图，每条灰色虚线就是一个残差。线性回归要做的，就是调整直线的位置和斜率，让所有这些虚线的长度平方和最小。这个方法有个名字，叫最小二乘法。

为什么是平方，不是直接取绝对值？两个原因。一是平方让大误差被放得更大，模型会更努力地避免离谱的预测。二是平方后的误差函数光滑、好求导——还记得上一篇的梯度下降吗？它需要能求导才能工作。

说白了就是：最小二乘给了"贴合"一个精确定义，也给了机器一个能优化的目标。到这一步，你已经把前几篇的"损失函数"具体化了——线性回归的损失，就是残差平方和。

## 两条路通向同一个答案

有了目标，怎么找到那条最优直线？这里有意思了——线性回归有两种完全不同的解法，而且都能到达同一个答案。

![正规方程与梯度下降两条路通向最优](two_roads.png)

第一条路叫正规方程。它厉害在哪？线性回归的损失函数是个规规矩矩的碗（数学上叫凸函数），碗底只有一个，还能用一个公式直接算出来。不用迭代，不用试，代入数据，一步到位。

```python
def fit_normal_equation(self, X, y):
    """正规方程闭式解：一个公式直接算出最优参数"""
    Xb = np.hstack([np.ones((len(X), 1)), X])   # 加一列 1 表示偏置
    theta = np.linalg.pinv(Xb.T @ Xb) @ Xb.T @ y
    self.intercept_, self.coef_ = theta[0], theta[1:]
```

第二条路，就是上一篇的梯度下降。从随便一个位置出发，算梯度、往下坡挪、重复，慢慢滑到碗底。

那问题来了——既然正规方程一步到位，为什么工业界还常用梯度下降这种慢慢挪的办法？

答案藏在那个公式里。正规方程要算一个矩阵的逆，当特征特别多（成千上万列）时，求逆的计算量会爆炸式增长，甚至根本算不动。而梯度下降不管多少特征，每一步都只是加加乘乘，还能一小批一小批地喂数据。所以数据小、特征少时用正规方程最省事；数据大、特征多时，梯度下降才是唯一现实的选择。

这也解释了一件事：为什么深度学习那些巨型模型全靠梯度下降训练——它们的参数动辄千亿，正规方程那个矩阵求逆，想都不用想。

## 你手写的，sklearn 一行搞定

理解了原理，现在看看真实工作里怎么用。

我们前面手写的那个 `fit_normal_equation`，加上梯度下降版本，一共几十行代码。而在工业界，同样的事情是这样的：

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)          # 训练
model.predict(X_new)     # 预测
```

三行。你手写几十行才实现的东西，sklearn 一行 `fit` 就搞定了。

![手写几十行与调用sklearn三行的对比](handwrite_vs_sklearn.png)

那我们费劲手写图什么？图的是你现在打开 `LinearRegression` 这个黑盒，知道里面到底在干嘛——它在用最小二乘定义"贴合"，在解那个碗的最低点，可能走正规方程也可能走梯度下降。以后调库时遇到问题，比如数据特征太多跑得慢、或者结果不对劲，你能猜到是哪一环出了岔子。

这就是这个系列的核心：**先手写弄懂原理，再放心调库。** 调库的人很多，知道库里在干嘛的人不多，后者才不会在出问题时抓瞎。

## 从一条直线，到万物预测

最后说一句线性回归的边界，免得你high过头。

线性回归只能拟合"直线关系"（多维时是平面/超平面）。现实里很多关系是弯的——比如药物剂量和疗效，加到一定程度反而有害。硬用直线去套弯的数据，就是上一篇说的欠拟合，怎么调都不准。

![直线套不住弯曲关系的欠拟合](line_vs_curve.png)

但它依然是最值得先学透的模型。一是它简单到能让你彻底看清"训练=优化损失"这条主线；二是它的思想会一路延续——下一篇的逻辑回归，你会发现它几乎就是线性回归套了一层壳，把"预测数值"变成了"预测类别"。

一条直线学到这，其实你已经摸到了监督学习的门。往后的算法，很多都是在回答同一个问题的不同变种：给定输入，怎么预测输出。

下一篇，我们让这条直线学会说"是"或"否"——逻辑回归，机器学习里最常用的分类算法。
