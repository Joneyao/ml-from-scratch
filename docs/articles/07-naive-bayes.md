# 从零开始学机器学习 #07：朴素贝叶斯——用概率"猜"类别

你的邮箱能自动把垃圾邮件挑出来，这个功能背后，几十年来一直站着一个"天真"的算法——朴素贝叶斯。

说它天真，是因为它做了一个明显不成立的假设，简单粗暴。但奇怪的是，就靠这个错误的假设，它把垃圾邮件过滤得又快又准，成了这个领域的经典方案。

上一篇的 KNN 靠"看邻居"分类，这一篇的朴素贝叶斯换一套完全不同的武器——概率。它不看你离谁近，而是算一笔概率账：出现这些特征的邮件，是垃圾邮件的概率有多大？这一篇讲清楚它怎么算这笔账，以及那个"天真"的假设到底天真在哪、为什么还管用。

## 贝叶斯：用证据不断更新判断

先说它名字里的"贝叶斯"。这来自贝叶斯定理，一个关于"如何用新证据更新判断"的数学规律。别怕定理两个字，它的直觉特别符合人的常识。

![贝叶斯用新证据不断更新判断](bayes_update.png)

想象你收到一封邮件，还没打开。凭经验，垃圾邮件大概占收件量的两成——这是你的初始判断，叫先验概率。

然后你瞟了一眼内容，看到"免费""中奖"这些词。这些就是证据。含这些词的邮件，是垃圾邮件的可能性明显更高。于是你把判断往上调——现在你觉得八成是垃圾邮件了。这个用证据更新后的判断，叫后验概率。

贝叶斯定理就是把这个"先验 → 看证据 → 更新为后验"的过程写成了公式。**它的核心不是背公式，而是这个思想：判断不是一锤定音，而是随着证据不断修正。**

朴素贝叶斯做分类，干的就是这件事：对一封新邮件，分别算"它是垃圾邮件的概率"和"它是正常邮件的概率"，哪个大就归哪类。

## "朴素"在哪：一个明知道错的假设

到这儿都很合理。那"朴素"这个略带贬义的词，从哪来的？

问题出在算概率时。一封邮件里有很多词，"免费""中奖""点击""链接"……要精确算"同时出现这一堆词、且是垃圾邮件"的概率，得考虑这些词之间的关联——比如"中奖"和"免费"经常一起出现，不是独立的。这种关联算起来极其复杂，数据再多也不够用。

朴素贝叶斯的解法简单粗暴：**假装所有词互相独立，谁出现都不影响谁。**

![朴素假设假装所有特征互不相关](naive.png)

看左边，现实里词和词之间有千丝万缕的联系。看右边，朴素贝叶斯一刀切断所有连线，假装它们互不相关。这样一来，"同时出现一堆词"的概率就能拆成每个词单独概率的连乘，计算一下子变得超简单。

这个假设显然是错的——"中奖"和"免费"当然相关。所以它叫"朴素"（naive，也就是天真）。

有意思的是，明知道假设错了，它的分类效果却常常好得出奇。原因在于：分类只要求"垃圾邮件的概率 > 正常邮件的概率"这个大小关系对就行，不要求概率算得绝对准确。就算因为忽略关联导致每个概率都有偏差，只要偏差不至于让大小关系翻转，最后的判断就是对的。**要的是排序对，不是数值准**——这是朴素贝叶斯能"带病工作"还工作得很好的关键。

## 跑一个真实的垃圾邮件分类

光讲原理不过瘾，我们用配套仓库里手写的朴素贝叶斯，真跑一个垃圾邮件分类。

训练数据很简单：几封已知的垃圾邮件（含"免费""中奖"多）和正常邮件（含"会议""报告"多），把每封邮件表示成各个词出现的次数。然后拿三封新邮件让模型判断：

![朴素贝叶斯垃圾邮件分类的真实输出](spam_demo.png)

这是代码真实跑出来的结果。"免费×2 中奖×1"的邮件被判为垃圾邮件，"会议×2 报告×1"被判为正常邮件——都符合直觉。模型学到的是：见到"免费""中奖"就往垃圾邮件那边算概率，见到"会议""报告"就往正常邮件那边算。

代码里还藏了一个小而关键的细节，叫拉普拉斯平滑。设想一个词在训练的垃圾邮件里从没出现过，那它在垃圾邮件里的概率就是 0，一连乘，整封邮件是垃圾邮件的概率被这个 0 直接清零——太武断了。拉普拉斯平滑的办法是给每个词的计数都先加个 1，保证没有任何概率是绝对的 0。这就避免了"一个没见过的词就一票否决"的尴尬。

## sklearn 一行，和它今天的位置

工业界用法照旧：

```python
from sklearn.naive_bayes import MultinomialNB
model = MultinomialNB()
model.fit(X, y)          # X 是词频矩阵
model.predict(X_new)
```

`MultinomialNB` 就是我们刚手写的那个多项式朴素贝叶斯，专门处理词频这类计数特征。还有个 `GaussianNB`，处理连续特征（比如身高、体重）。原理一样，只是算单个特征概率的方式不同。

![高斯朴素贝叶斯在鸢尾花上的决策边界](b4_naive_bayes_boundary.png)

这是用连续特征版的 `GaussianNB` 给鸢尾花分类画出的决策边界——同样是那套"算概率、比大小"的逻辑，只是每个特征的概率改用高斯分布来估。

朴素贝叶斯今天还有用吗？有。它训练极快、内存占用小、对小数据集友好，是很多文本分类任务的强基线——你要做一个新的分类器，常常先用它跑一版看看效果，作为对比的底线。垃圾邮件、新闻分类、情感分析这些场景，它至今仍在第一线。

它给我们的启发也很特别：**一个明知道错的假设，只要错得"不影响大局"，照样能造出好用的工具。** 机器学习里，能用的近似常常比完美的精确更值钱。

下一篇聊一个你一定见过、甚至天天在用的思维方式——决策树。它把分类变成一连串"是非题"，是机器学习里最像人类推理的算法。
