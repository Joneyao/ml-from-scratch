# 从零开始学机器学习 #15：异常检测——怎么找出数据里的"怪东西"

你的信用卡突然在异地刷了一笔大额消费，银行几秒钟内就短信问你"是否本人操作"。工厂里一台设备的振动数据出现了细微异常，系统提前预警避免了停产。这背后都是同一类技术在工作——异常检测。

它要解决的问题，和前面所有算法都不太一样。前面我们要么分类、要么聚类、要么降维，处理的都是"大量的、成堆的"数据。异常检测反过来——它要在一大堆正常里，揪出那极少数"不对劲"的。

这一篇是无监督学习的最后一站。核心思想朴素得一句话就能说清：**异常，就是少见；少见，就是概率低。** 但要真正做好它，有个天生的难点绕不过去。

## 异常检测，和它天生的偏心

先想清楚异常检测的处境有多特殊。

正常和异常的数量，天差地别。1000 笔交易里可能只有几笔是盗刷，1000 个零件里可能只有几个次品。异常天生就是极少数——这在机器学习里叫极端的类别不平衡。

![异常检测难点异常天生少模型容易全判正常偷懒](imbalance.png)

这个不平衡带来一个致命陷阱，第十二篇讲模型评估时我们见过它的雏形：如果异常只占 1%，一个偷懒的模型只要把所有东西都判成"正常"，准确率就有 99%。可它一个异常都没抓到，毫无用处。

所以异常检测不能用准确率来衡量，也不能用普通的分类思路硬套（正例太少，模型根本学不好）。它需要换一个角度：**不去学"异常长什么样"（异常太少、花样太多，学不过来），而是学"正常长什么样"，然后把不符合正常模式的都拎出来。**

这个转变是理解异常检测的钥匙。它是一种"排除法"——先把正常摸透，剩下不正常的自然就浮现了。

## 核心直觉：异常 = 少见 = 概率低

怎么判断一个点"不符合正常模式"？最经典的办法基于概率。

先用大量正常数据，估计出"正常数据长什么样"——具体说，是估计它的概率分布。然后对任何一个新样本，算它出现的概率。概率高，说明它和大家一样普通；概率低，说明它是个稀客，很可能就是异常。

![异常检测的核心直觉异常等于少见等于概率低](anomaly_rare.png)

看这条钟形曲线（正态分布）。绝大多数正常数据都挤在中间概率高的地方（蓝色区）。而两侧的尾巴（红色区），概率极低——一个点如果落在这里，意味着它偏离正常太远，就该被标记为异常。

设一个概率门槛：低于它的判为异常，高于它的判为正常。就这么简单。

用配套仓库手写的高斯异常检测器，真跑一下：

![异常检测正常点扎堆离群点被高斯密度揪出](d3_anomaly.png)

蓝色的点是正常数据，扎堆聚在中间。那些散落在四周、远离人群的点，被算法用红叉标了出来——它们所在的位置概率极低，正是"稀客"。算法全程没人告诉它哪些是异常，它纯粹靠"这个点太少见了"就把异常揪了出来。

说白了就是：**异常检测不认识异常，它只认识正常——凡是不像正常的，就是异常。**

## 两种朴素但好用的做法

具体怎么算概率、定门槛？入门有两种简单方法，配套仓库里都手写了。

![高斯密度法与Z-score法两种入门做法](two_methods.png)

**第一种，高斯密度法。** 假设正常数据服从高斯分布，用正常数据估出每个特征的均值和方差，然后算每个样本的概率密度。密度低于门槛就是异常。上面那张红叉图就是它跑出来的。它的好处是有明确的概率解释，门槛可以根据"预期异常比例"来定。

**第二种，Z-score 法（标准分数）。** 更直白：看一个值偏离均值多少个标准差。有个经验法则叫"三西格玛"——正常数据约 99.7% 落在均值正负 3 个标准差以内。所以只要某个样本偏离均值超过 3 个标准差，就当它是异常。

```python
class ZScoreDetector:
    def predict(self, X):
        z = np.abs((X - self.mu_) / self.sigma_)   # 偏离几个标准差
        return np.where(np.any(z > self.k, axis=1), -1, 1)  # 超过 k 就判异常
```

几行代码，思路却很实用——很多监控系统的第一版告警规则，本质就是 Z-score：某个指标超出正常范围几个标准差，就报警。

这两种方法都简单，也都有局限：它们假设数据大致是"一团"的（高斯形状）。遇到复杂分布，就得用更强的方法，比如孤立森林（Isolation Forest）——它换了个思路，"异常点更容易被随机切分孤立出来"，特别适合高维复杂数据。但入门理解异常检测，从"概率低=异常"这个直觉出发最清楚。

## sklearn 一行，和它守护的日常

工业界用法（以孤立森林为例）：

```python
from sklearn.ensemble import IsolationForest
model = IsolationForest(contamination=0.05)   # 预期 5% 是异常
model.fit(X)
model.predict(X_new)   # 返回 1（正常）或 -1（异常）
```

那个 `contamination`（预期异常比例），就对应我们手写高斯检测器里"定门槛"的参数——你现在知道它在调什么了。

![异常检测的日常应用金融设备安全运维](applications.png)

异常检测的应用，安静地遍布在你生活的每个角落。金融风控里揪盗刷和欺诈，工业里做设备故障预警，网络安全里检测入侵，医疗里发现异常体征，运维里监控服务器指标突变。它们的共同点都是：正常的东西压倒性地多，而真正要抓的、代价最高的，恰恰是那极少数异常。

到这里，无监督学习三篇讲完了：K-Means 找结构、PCA 降维度、异常检测揪异常。它们的共同点是都没用标签，全靠数据自身的规律说话。这也让你对"机器学习"有了更完整的认识——它不只是"看着答案学"，也能在没有答案的地方，挖出隐藏的模式。
