# 从零开始学机器学习 #06：KNN——最"懒"的算法，不训练也能预测

前面几篇的算法都有一个共同套路：喂数据、算损失、梯度下降调参数，训练出一组 `w` 和 `b`。训练完，原始数据就可以扔了，模型只留下那几个参数。

这一篇的主角，KNN，偏不走这套。

它没有"训练"这个步骤——准确说，它的训练就是把数据原样存下来，一个参数都不算。所有的功夫，它都推迟到你让它预测的那一刻。听起来懒得离谱，可它简单、直观，某些场景下还特别好用。理解它，你会对"什么才算学习"这件事有新的认识。

## 物以类聚：看你的邻居是谁

KNN 的全名是 K 近邻（K-Nearest Neighbors），思想一句话能说完：**要判断一个新样本是哪类，就看它最近的 K 个邻居里哪类最多。**

这不就是"物以类聚，人以群分"吗。想知道一个陌生人大概是什么样的人，看他常来往的几个朋友就有谱了。

![KNN看最近的K个邻居投票决定类别](look_at_neighbors.png)

看这张图。绿色星星是个待分类的新点，我们要判断它是红类还是蓝类。KNN 的做法：找出离它最近的 5 个点（K=5），数一数这 5 个里红的多还是蓝的多。图里这 5 个邻居全是蓝的，那这个新点就判为蓝类。

就这么简单。没有公式，没有参数，没有训练。要预测时，算出新点到所有已知点的距离，挑最近的 K 个，投票。

"距离"怎么算？最常用的是欧氏距离，就是中学学的两点间直线距离，多维时同理。距离近，说明两个样本在特征上像，KNN 赌的就是"长得像的东西大概率是一类"。

## 它凭什么叫"最懒的算法"

刚才说 KNN 没有训练步骤，这话值得展开——因为它揭示了两种截然不同的学习哲学。

![KNN惰性学习把功夫推到预测时刻](lazy_vs_eager.png)

一般的模型是"勤奋型"：训练时吭哧吭哧算参数，累得半死；等到预测，套个公式就出结果，轻松。前面几篇的线性回归、逻辑回归都是这样。

KNN 是"惰性型"：训练时啥也不干，就把数据原样存下来；等到要预测了，才临时抱佛脚——现场计算新点到每一个存下来的点的距离，找出最近的邻居。

这就是为什么 KNN 被正式归类为"惰性学习"（lazy learning）。它把该在训练时做的活，全拖到了预测时。

这种"懒"有代价。数据量一大，麻烦就来了：每预测一个新点，都要和成千上万个存下来的点逐个算距离。数据一百万条，预测一次就要算一百万次距离。所以 KNN 不适合大数据、也不适合要求实时响应的场景。

但它也有勤奋模型给不了的好处：加新数据不用重新训练，直接扔进存储就行。数据天天变、又不大的场景，KNN 反而省心。

## K 该选几：一个不能省的选择

KNN 只有一个要你操心的旋钮——K，也就是看几个邻居。别小看这一个数，它直接决定模型的脾气。

![KNN不同K值决策边界从锯齿到平滑](b3_knn_kvalues.png)

看这三张真实跑出来的决策边界图。

K=1，只看最近的那一个邻居。边界锯齿状，扭曲得厉害，甚至在蓝色地盘里圈出几个红色小岛——它把每一个孤立的点都当回事，包括那些可能是噪声的点。这就是过拟合，还记得第三篇那个背答案的学生吗？K=1 就是它。

K=25，看最近的 25 个邻居投票。边界变得平滑，个别噪声点淹没在多数里，翻不起浪。但 K 要是太大就走向另一个极端——万一 K 大到把全部样本都算进来，那不管新点在哪，永远投给样本最多的那类，模型就废了，这叫欠拟合。

K=5，在两者之间，边界既抓住了大势又不被个别点带偏。

所以选 K 是在过拟合和欠拟合之间走钢丝——**K 太小容易被噪声带偏，K 太大又会忽略局部规律。** 实践里没有万能的 K，通常拿一部分数据试几个 K 值，看哪个在测试集上表现最好。这个"试出最佳 K"的过程，就是第三篇讲的用测试集做模型选择。

## sklearn 三行，和 KNN 的软肋

老规矩，工业界用法：

```python
from sklearn.neighbors import KNeighborsClassifier
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X, y)              # 其实只是把数据存起来
model.predict(X_new)
```

注意那个 `fit`——名字叫拟合，可对 KNN 来说，它干的只是把数据存进去，没有任何参数被计算。这是你懂了原理才能会心一笑的细节。

最后提一个 KNN 的软肋，叫维度灾难。KNN 靠距离判断相似度，可当特征维度很高（几百上千维）时，所有点两两之间的距离会变得差不多远——"最近的邻居"和"最远的邻居"没啥区别了，投票也就失去了意义。

![维度越高最近与最远邻居越难区分](curse_dim.png)

这张图是真跑出来的：横轴是特征维度，纵轴是"最近距离除以最远距离"。维度一高，这个比值就往 1 爬——意思是最近的邻居和最远的邻居几乎一样远，KNN 赖以工作的"远近"彻底失效。所以 KNN 在低维数据上好用，维度一高就容易失灵。这也是为什么高维数据（比如图像、文本）通常得先降维——而降维正是这个系列后面要讲的 PCA 干的活。

KNN 教会我们一件事：机器学习不一定非要"训练出参数"。有时候，把数据记住、用相似度直接判断，反而是最朴素也最有效的办法。
