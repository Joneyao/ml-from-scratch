# 从零开始学机器学习 #13：K-Means——机器怎么自己"分堆"

前面十二篇，所有算法都靠一样东西才能学习——标准答案。判断猫狗，得先有标好"猫""狗"的照片；预测房价，得先有真实成交价。这种"看着答案学"的方式，叫监督学习。

但现实里，大量数据是没有答案的。

一堆用户的行为记录，没人告诉你谁是"高价值用户"谁是"流失风险";一批新闻，没人提前标好类别。这时候还能让机器学到东西吗？能。这类"没有答案也要学"的方法，叫无监督学习。这一篇的 K-Means 聚类，是无监督学习最经典的入门算法——它能把一堆没有标签的数据，自动分成几堆。

## 没有答案，机器学什么

先看清楚监督和无监督的根本区别。

![有没有标准答案是监督和无监督的分水岭](sup_vs_unsup.png)

左边是监督学习看到的数据：每个点自带颜色（标签），机器的任务是学会"给新点上色"。右边是无监督学习看到的：一堆灰扑扑的点，没有任何颜色，机器得自己看出"这些点好像能分成几堆"。

无监督学习学的不是"输入到答案的映射"，而是**数据自身的结构**。K-Means 要回答的具体问题是：这堆点能不能自然地分成 K 堆，每一堆内部的点互相靠近、堆与堆之间离得开？

这件事有实实在在的用处。电商把用户聚成几类做精准运营，新闻网站把文章聚类做推荐，生物学家把基因表达聚类找规律——都不需要预先的标签，让数据自己说话。

那机器怎么在没有答案的情况下"分堆"？K-Means 的办法简单得让人意外。

## 分配、更新，反复几轮就收敛

K-Means 名字里的 K，就是你想分成几堆。假设你决定分 3 堆，它的流程只有两步，循环做：

![K-Means分配更新反复几轮就收敛](kmeans_iter.png)

**第一步，随便丢 K 个"质心"。** 质心就是每一堆的中心点。一开始机器啥也不知道，就在数据里随机挑 3 个点当初始质心（图里第一张的三颗红星）。

**第二步，分配。** 每个数据点看看自己离哪个质心最近，就归到那一堆（图里点被染成了三种颜色）。

**第三步，更新。** 每一堆现在有了成员，就把质心移动到这堆成员的正中间（所有成员坐标的平均值）。

然后回到第二步：质心动了，有些点离最近质心的归属可能变了，重新分配，再更新质心……如此反复。神奇的是，这个"分配-更新"的循环，几轮之后质心就基本不动了（图里第三张，质心稳稳停在三堆的中心）。这时候就收敛了，分堆完成。

```python
def fit(self, X):
    centroids = X[random_pick(k)]           # 随便挑 k 个当初始质心
    for _ in range(max_iters):
        labels = assign_nearest(X, centroids)   # 每点归到最近质心
        new_centroids = update_means(X, labels) # 质心移到各堆中心
        if converged(centroids, new_centroids):
            break
        centroids = new_centroids
```

说白了就是：**K-Means 不停地"就近抱团、然后重新定中心"，抱着抱着就把数据分清楚了。** 它没有标签也能干活，靠的就是"物以类聚"这个几何直觉。

## 两个绕不开的坑：K 怎么定，结果会晃

K-Means 好用，但有两个坑，用之前必须知道。

**第一个坑：K 是你自己定的。** 算法不会告诉你该分几堆，K 是超参数，得你指定。分错了 K，结果就没意义——本来是 3 类硬分成 5 类，会把一个自然的堆劈开。怎么定 K？常用"肘部法则"。

![K-Means聚类结果与肘部法则选K](d1_kmeans.png)

看这张真实跑出来的图。左边是 K-Means 把点分成 3 堆的结果，红星是质心，分得干干净净。右边是肘部法则：横轴是 K，纵轴是"簇内平方和"（每个点到自己质心的距离平方总和，衡量堆得紧不紧）。K 越大这个值越小，但你看曲线在 K=3 处有个明显的"拐弯"，像手肘——拐点之后再加 K，改善就不明显了。这个肘部对应的 K，通常就是比较合理的选择。

**第二个坑：结果会晃。** 还记得第一步"随便丢质心"吗？丢在哪是随机的，而不同的初始位置，可能收敛到不同的结果。运气不好，质心会卡在一个不太好的局部最优上——同样的数据，两次运行可能分出不太一样的堆。

实践中的应对：多跑几次（用不同的随机初始化），挑"簇内平方和"最小的那次结果。这也是 sklearn 默认的做法。这个"随机初始化影响结果"的特性，是 K-Means 一个绕不开的软肋，用的时候心里要有数。

## sklearn 三行，和聚类的边界

工业界用法：

```python
from sklearn.cluster import KMeans
model = KMeans(n_clusters=3, n_init=10)   # 分3堆，跑10次取最好
model.fit(X)
model.labels_          # 每个点属于哪一堆
```

`n_clusters` 就是 K，`n_init` 就是"多跑几次防止运气差"——你现在知道这俩参数背后的道理了。

K-Means 也不是万能的。它假设每一堆都是"圆形"的、大小差不多，遇到形状怪异的簇（比如两个交缠的月牙）就分不好。这种情况要用别的聚类方法（如 DBSCAN）。

![K-Means擅长圆形簇遇月牙形就分错](kmeans_limit.png)

看这张对比就明白了：左边圆滚滚的两簇，K-Means 分得干净利落；右边两个交缠的月牙，它却硬按"就近抱团"的规则把它们拦腰切开——因为它心里的"堆"永远是圆的。但作为无监督的入门，K-Means 那个"分配-更新"的循环，是理解"机器如何在无答案下自组织"的最佳起点。

它给我们的启发是：**学习不一定需要老师。** 只要数据本身有结构，机器就能靠简单的规则把结构挖出来。这是无监督学习最迷人的地方。
