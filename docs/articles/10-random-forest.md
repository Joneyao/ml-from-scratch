# 从零开始学机器学习 #10：随机森林——三个臭皮匠的数学证明

"三个臭皮匠，顶个诸葛亮"这句老话，在机器学习里不是鸡汤，是有严格数学证明的定理。

上一篇结尾我们说到，单棵决策树有个毛病：不稳定，还容易过拟合。这一篇的随机森林，就是解决这个毛病的经典方案——它不训练一棵完美的树，而是种一整片各有缺陷的树，让它们投票。神奇的是，一堆平庸的树投票的结果，往往比任何一棵单独的树都准得多。

这背后不是玄学。这一篇讲清楚：为什么"一群蠢模型"能拼出一个聪明模型，以及要满足什么条件才行——那个条件，恰恰是随机森林里"随机"两个字的由来。

## 一群普通的树，怎么胜过一棵好树

先看结论，用配套仓库里手写的随机森林，在真实的乳腺癌诊断数据上跑一下：

![随机森林树越多越稳越准](c1_forest_vs_tree.png)

红色虚线是单棵决策树的准确率。绿线是随机森林——随着森林里树的棵数增加，准确率稳稳地爬上去，超过了单棵树，然后趋于平稳。树越多，越稳越准。

这就是集成学习的威力：把多个模型组合起来，效果超过其中任何一个。随机森林是其中最经典、最好用的一种。

但这里有个反直觉的地方。如果每棵树都不够好，把它们凑一起，不应该是"一堆错误加起来还是错"吗？为什么反而更准了？

答案藏在一个条件里。

## 为什么"三个臭皮匠"能成：错得要不一样

三个臭皮匠顶个诸葛亮，有个前提常被忽略：**这三个臭皮匠犯的错必须不一样。**

想象一个投票场景：一道判断题，每个人答对的概率是 70%（比瞎猜的 50% 强，但不算高）。如果找很多这样的人来投票，取多数意见，结果会怎样？

![投票纠错错得不一样才能互相抵消](vote.png)

看这张图。单个人 70% 的正确率（红线）。但只要人够多、而且每个人是独立判断的，多数投票的正确率（绿线）会一路爬到 90% 以上。

道理在于：每个人偶尔答错，但错的地方各不相同。张三在这题栽了，李四王五没栽，投票时张三的错误就被多数正确票淹没了。**错误因为不一样而互相抵消，正确因为方向一致而叠加。** 这就是集成的数学本质。

但如果反过来——所有人都在同一道题上犯同样的错（比如他们都背了同一份错误答案），那投票再多也没用，错误不会抵消，只会一致地错下去。

所以集成能成的关键条件是：每个模型不仅要比瞎猜强，还要**各自独立、错得不一样**。怎么让一片树"错得不一样"？这就是随机森林"随机"二字的任务了。

## 两把"随机"，让每棵树都长得不一样

随机森林用两把随机，逼着每棵树都长成不同的样子。

![Bagging每棵树看随机的数据和特征](bagging.png)

**第一把随机：数据随机（Bagging）。** 不让每棵树看全部数据，而是从训练集里有放回地随机抽一批给它。有放回意味着同一个样本可能被抽中好几次，也可能一次都没抽到。于是每棵树看到的数据都略有不同，长出来自然不一样。这个技术叫 Bagging，是"Bootstrap Aggregating"的缩写。

**第二把随机：特征随机。** 每棵树在每次分裂时，不看全部特征，只从随机挑出的一部分特征里选最佳分裂。这样即使两棵树看到相似的数据，也会因为可选特征不同而做出不同的判断。

```python
class RandomForest:
    def fit(self, X, y):
        for _ in range(self.n_trees):
            idx = rng.integers(0, len(X), len(X))     # 有放回抽样
            feat = rng.choice(n_features, k, replace=False)  # 随机选特征
            tree = DecisionTree(max_depth=self.max_depth)
            tree.fit(X[idx][:, feat], y[idx])         # 用这份随机数据+特征训练
            self.trees_.append(tree)
```

两把随机一叠加，每棵树都成了"带着不同偏见的臭皮匠"。它们各自都不完美，甚至有点笨，但正因为笨得不一样，投票时错误互相抵消，森林整体就变得又准又稳。

说白了就是：**随机森林故意让每棵树变弱变怪，就为了让它们的错误不重样。** 这是它设计里最反直觉、也最精妙的一点。

## sklearn 一行，和它至今的江湖地位

工业界用法：

```python
from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100)   # 100 棵树
model.fit(X, y)
model.predict(X_new)
```

`n_estimators` 就是树的棵数，也就是我们图里那条爬升的绿线的横轴。

![随机森林三大实用优点省心稳可解释](strengths.png)

随机森林是机器学习里的"劳模"——不用怎么调参就能给出相当好的结果，对各种数据都稳，还自带评估特征重要性的能力（告诉你哪些特征对预测最关键）。在结构化的表格数据上，它至今是最受欢迎的算法之一，很多数据科学家上手一个新问题，第一个跑的基线就是它。

它给我们的启发超出了算法本身：**与其苦苦追求一个完美的模型，不如聪明地组合一堆不完美的模型。** 这个"集体智慧胜过个体天才"的思想，是集成学习的灵魂。

下一篇讲另一种组合思路。随机森林是让一群树各自独立、并行投票；下一篇的 GBDT 反着来——让树们排成一队，后一棵专门纠正前一棵的错。一个求同，一个补短，殊途同归。
